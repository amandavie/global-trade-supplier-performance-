# Global Trade & Supplier Performance Analytics

This project analyzes international trade flows and supplier delivery performance.

## Project Objective

The project has two main parts:

1. Analyze public import/export data by country and product category.
2. Analyze shipment-level data to evaluate supplier performance and delivery delays.

## Business Questions

- Which countries are Brazil’s main import and export partners?
- Which product categories have the highest trade value?
- Which suppliers have the lowest on-time delivery rate?
- Which suppliers and shipment modes cause the most delays?
- What is the average delay in days for each supplier?

## Data Sources

- UN Comtrade — public international trade statistics
- Kaggle Supply Chain Shipment Pricing Data — shipment-level supplier and delivery data

## Tools

- Python for data cleaning and analysis
- SQL for data queries and validation
- Power BI for dashboard development
- GitHub for documentation and version control
